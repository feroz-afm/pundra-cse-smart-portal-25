# User Guide

1. **Log in** with the admin account (or register a new account).
2. Pick a module from the **sidebar** on the left.
3. The **Records** list shows short entries; click one to see its full details on the right.
4. Use **Insert/Add**, **Update**, **Delete** and **Refresh** in the action bar. Update and Delete work on the
   record selected in the list.
5. **Forgot password:** a 4-digit reset code is written to `data/mail_logs.txt`.
6. **Start fresh:** close the app and run `reset_data.bat` (Windows) or `reset_data.sh`; default data is loaded
   again on the next start.

All data is saved automatically in plain-text files inside `data/`.
